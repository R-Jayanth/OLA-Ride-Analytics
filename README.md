# OLA Ride Analytics Dashboard

## Project Overview
An interactive Power BI dashboard built to analyze OLA ride-booking data, revenue, vehicle performance, customer ratings, payment methods, and booking cancellations.

## Dashboard Features

### 1. Ride Performance Overview
- Total revenue
- Total rides
- Revenue growth percentage
- Average customer rating
- Top vehicle insight

### 2. Booking Analysis
- Ride volume over time
- Booking status breakdown
- Successful and cancelled bookings
- Driver and customer cancellation analysis

### 3. Vehicle Performance
- Top vehicle types by ride distance
- Ride distance distribution per day
- Average customer ratings by vehicle type

### 4. Revenue and Customer Insights
- Revenue by payment method
- Top customers by total booking value
- Customer versus driver ratings

### 5. Cancellation Analysis
- Cancellation reasons reported by customers
- Cancellation reasons associated with drivers
- Comparison of cancellation categories

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Dashboard Development

## Key Observations
- The dashboard displays ₹56.53M in total revenue and 103K total rides.
- Prime Sedan has the highest ride distance among the vehicle types shown.
- Successful bookings are the largest category in the booking status breakdown.
- Payment revenue, customer ratings, and cancellation reasons are explored through dedicated visualizations.
